# Feira de Ciências — código-fonte

Este pacote contém o código-fonte original exportado da Emergent.

## Importante
Este ZIP ainda NÃO é uma versão migrada e publicada. Ele preserva o projeto original.
Antes de publicar fora da Emergent, será necessário substituir/configurar:
- autenticação Google atualmente ligada à Emergent;
- armazenamento de fotos atualmente ligado à Emergent;
- variáveis de ambiente e banco de dados;
- configuração de hospedagem do frontend e backend.

## Envio pelo celular
O GitHub não extrai arquivos ZIP automaticamente. É necessário extrair este pacote no celular e enviar o conteúdo extraído, mantendo as pastas `frontend`, `backend` e `tests` na raiz do repositório.
